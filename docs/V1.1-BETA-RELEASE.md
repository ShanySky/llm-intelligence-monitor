## 本次交付

- 不重新研发框架。继续使用 V1 `v0.1.0-beta.1` 的手动 Core 评测工作流、评分与结果持久化。
- 现有 `frontier-batch-screen.yml` 的默认手动配置为 **`v1.1-report`：免费汇总历史公开工程题证据**。该路径已通过 GitHub Actions，无模型 API 调用。
- 新增明确付费选择的 **`v1.1-task`：一次一个原版任务、一个模型、一个思考档位**。可选 Luna / Sol Medium、High、X High；不通过条件不运行模型。原有研究 `frontier-batch` 功能保留，不是默认选项。
- 官方测试原版，不强制人为 60/80/95 目标分。模型任务在断网容器；只有依赖预热和独立评分器可以联网。保留 200k 输入 Token、30 Responses、40 Shell、540 秒保护。
- 报告包含模型、档位、原版案例、得分、耗时、Token、数据有效性、来源历史。区分 Coverage、候选差异和无效预算/环境样本；历史报告不冒充实时模型排名。
- 原 V1 Core 单独的 [application-final-validation](../.github/workflows/application-final-validation.yml) 工作流不改；未恢复自动日测；未改变主流用户的默认付费行为。
