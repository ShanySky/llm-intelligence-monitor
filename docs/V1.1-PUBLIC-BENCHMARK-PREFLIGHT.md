# Official public benchmark environment admission

This check runs **zero model calls**. It uses a pinned, official SWE-bench Multilingual task and its official evaluation script.

The existing `frontier-batch-screen.yml` Workflow contains a separately gated `public-source-preflight` job, executed only on the dedicated push trigger. Regular changes are unaffected. First probe: `google__gson-2311`.

Pipeline: verify shortlist entry / pinned commit → fetch official eval and patches → pull specified image with 180s hard timeout → confirm baseline fails official tests → apply official gold patch → confirm official tests pass. Emit `result.json` and bounded logs in an Actions artifact; failures are `incomplete_environment`, **never** 0-point model results. The temporary reference and test patches stay exclusively inside preflight and must not enter any model workspace.

If Docker image pull or official evaluation cannot finish within the budget, stop this source or pick a smaller existing candidate rather than expanding cost. Only tasks with positive official baseline/reference evidence may move to a single Luna High probe; this Job never invokes a model.
