# V1.1 public task dependency warmup without model spend

For **Gson 2158 / 2311** and **Axios 5316**, the original source-image build lacks some runtime testing dependencies. The prior fix moved the official grader to a different networked container; now we additionally make the *model workspace itself* able to run original local tests while offline.

- Source-only connected warmup: on the exact pinned upstream source, run an **existing test** to resolve Gson Maven Surefire providers, or install Axios npm dependencies (including `formdata-node`, needed by upstream additional tests) without saving into its package manifest.
- Verify that **no tracked source file changed** (git diff) and that neither `gold.patch` nor `test.patch` has been placed in this workspace.
- Disconnect Docker bridge, assert no attached network remains, run an ordinary existing local test to ensure offline execution works.
- In the **no-model preflight only**, apply the official extra tests and gold patch *after* offline smoke testing to this disposable container and check F2P baseline FAIL / gold PASS, entirely offline. This validates the grade cannot be confounded by unprepared test deps in an offline container.
- Only when this reference admission passes should the existing Luna/Sol runner invoke `v11-public-agent-deps.sh` in the pre-model phase. Keep the grading container independent, network connected, and inaccessible to the model. Do not change official test semantics or thinking budgets.

A failure is infrastructure-incomplete; do not run a paid model or score it zero. This gate uses the existing `frontier-batch-screen.yml` Workflow and never starts an LLM.

## Verified outcome (2026-10-08)

[GitHub Actions #37764439033](https://github.com/ShanySky/llm-intelligence-monitor/actions/runs/37764439033) passed **3/3 tasks** with no model calls: Gson 2158 73s, Gson 2311 121s, Axios 5316 98s. Every case: connected original-project dependency preparation succeeded; source remained identical; Docker bridge was disconnected; an ordinary existing local test completed offline; official extra tests failed on baseline and passed with the gold patch offline.

This exact helper is now invoked from both Luna and Sol official benchmark runner scripts **before** any model API call, guarded by `benchmarks/v1.1-agent-warmup-admission.json`. A missing/failed local test or remaining Docker network causes a hard abort before billing. Gold/test patches remain exclusively in reference-only preflight and the separate official grader, never in a model task workspace. Both paid triggers remain disabled.
