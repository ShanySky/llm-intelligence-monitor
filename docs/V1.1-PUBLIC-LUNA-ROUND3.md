# V1.1: third public candidate attempt, bounded by source admission

Three original SWE-bench Multilingual engineering issues selected **before** model trials:
- Java Gson `google__gson-1093`: lenient JsonWriter stream behavior (a local API consistency bug)
- Vue `vuejs__core-11739`: SSR hydration / CSS variables (cross-module rendering behavior)
- Java Lombok `projectlombok__lombok-3422`: `@Helper` annotation AST transformation on method-local class (higher build-cost risk)

This is a candidate screening, **not a constructed 60-point exam**. Source used without modifications. Only official baseline→gold checks and offline agent local-test preparation may admit cases. No paid model calls until environmental tests pass. Keep a small 2–3 task cohort, do not expand high-cost Lombok if it cannot meet run budget, and do not rerun four previous Luna 100-point tasks. Stop this search direction if there is no middle-difficulty signal in the bounded next round.

Reports retain original issue identity, agent budgets, official source version, and reasons for exclusion. Sol/Astra not run; main branch untouched.
