# V1.1: Repair offline test dependency mismatch without model reruns

**Cause independently confirmed in GitHub Actions #37762262751:**
- Gson 2158: Maven Surefire needs `surefire-junit4:3.0.0-M7` from Maven Central, absent from image.
- Gson 2311: Maven Surefire needs `surefire-junit4:3.0.0-M8`, absent from image.
- Axios 5316: `npm` attempts to fetch `formdata-node` from npmjs.org and fails `EAI_AGAIN` under `--network none`.

**Fix:** keep the real model agent in `--network none` (unchanged). Only *after the model ends*, copy the immutable diff into a **fresh separate Docker verifier with `--network bridge`** and run the same official test script. The verifier may fetch missing dependencies. It is never accessible to the model and receives no model credentials.

**Validation:** for every affected task, first run official baseline FAIL → gold PASS with a connected verifier, **without a model call**, and then regrade the model patch saved in the exact original GitHub Actions artifacts. The patches come from Luna High runs #37758488863 and #37759079285; the new score is published next to the original score with unchanged source run ID and patch hash. Never pretend this is a fresh model run. Any dependency/timeout/patch failure gives null quality.

Once the three regrades are complete, use the existing two official Vue results (which already passed gold under network-none) to compute the corrected original five-task cohort. Do not edit official tests, scores or hints; do not rerun the model or additional thinking tiers. Existing V1 Core and daily schedule stay unchanged.
