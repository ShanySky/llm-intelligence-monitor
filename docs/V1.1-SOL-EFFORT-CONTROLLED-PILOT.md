# V1.1 Sol 6.1 思考档位一次性对照

在 V1.1 Beta 发布后，**只验证最小充分的档位区分信号**，而不重新开始盲目筛题。

- 原版官方问题：`vuejs__core-11899`，SWE-bench Multilingual 固定源码。
- 历史先验：Sol High 在原题上官方评分为 0，Luna High 为 0，但不同工具/预算限制之间不能直接做长期对比；选它是为了避免前一批测试的满分天花板。
- 同一模型 `gpt-6.1-sol`，同一题目及固定 Harness：Medium / High / X High 各一次。
- 每档 Agent 最多 30 responses、40 shell、540 秒、20 万累计输入 Token（检查后再决定是否继续下次调用），不重复抽样。独立评分器照原版官方测试验证。
- 独立历史分支 `v11-sol-effort-results`；记录样本有效性、0/100 官方结果、输入/输出/思考 Token、响应轮次及实际用时。
- 存在超时、预算上限或基础设施失败，分数为空，不得记零分；单道题单次运行只可作为待复验信号，不能断言档位强弱。
- 只复用现有 Workflow，原 V1.1 默认的免费 `v1.1-report` 不变，V1 保留。
- 本轮禁止自动追加第二题、Sol XHigh 重试、Astra 或额外工作流次数；无信号及时停止。
