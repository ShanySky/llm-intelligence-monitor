# V1.1 one-task official SWE-bench Luna High pilot

Reuses the existing agent runner and frontier Workflow (new gated job only, **no new Workflow**). This is **one** paid model probe, not a formal ranking.

Admission checks: `benchmarks/v1.1-public-candidates.json` task must have official Docker baseline failure + reference pass; the runner is pinned to Luna High and official commit. Model sees only original `problem_statement.md` plus original repository at the fixed baseline commit. Official `eval.sh` arrives in Docker **after** the model has finished; gold/test patches are never put into the agent container before model completion.

Agent time limit is 540s, tool limits 30 Responses and 40 Shell; official evaluator execution is separate. Preserve model patch, token telemetry, raw verifier log and objective binary score. Model timeout/infra/cap exhaustion yields *null quality and invalid sample*, not zero. A passing or failing **single** model attempt is only screening evidence.

Results go to `v11-public-luna-results` branch and per-run artifact. **Do not expand to Sol or Astra until stable Luna screening and task-specific constraints have been validated.**
